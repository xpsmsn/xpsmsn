## 🧭 我是谁

体育专业出身，在学生工作一线做辅导员、学院团委书记。对世界充满好奇，自学过前端，如今在 AI 的陪伴下走上了编程的路——大多是 vibecoding，但**每一个需求都来自真实的现场**。

学生工作的日常里堆满了事务性、重复性的劳动。于是我给自己立了一条主线：

> **把重复的交给机器，把时间还给人——还给育人，也还给创作。**

法律速查、通讯录转换、学生工作台、设计系统……我的每个项目，都长在这条主线的延长线上。代码之外，我还是**全模态 AI 的实践者**：图像、音频、歌曲、视频，ComfyUI 的工作流亲手跑过，也养着一个自己的 AI 歌手。

🔭 **在做的**：把学生工作里的重复劳动，一个个变成顺手的工具
🎛 **在实验的**：全模态生成（图 / 音 / 歌 / 视频）、Agent 工程、RAG 检索
💬 **可以聊**：AI 工具落地、学生工作提效、教育信息化、UI 设计规范
