## 🧭 我是谁

体育专业出身，在学生工作一线做辅导员。对世界充满好奇，自学过前端，如今在 AI 的陪伴下走上了编程的路——大多是 vibecoding，但**每一个需求都来自真实的现场**。

学生工作的日常里堆满了事务性、重复性的劳动。于是我给自己立了一条主线：

> **把重复的交给机器，把时间还给人——还给育人，也还给创作。**

法律速查、通讯录转换、学生工作台、公文写作、思政聚合站……我的每个项目，都长在这条主线的延长线上。代码之外，我还是**全模态 AI 的实践者**：图像、音频、歌曲、视频，ComfyUI 的工作流亲手跑过，也养着一个自己的 AI 歌手。

🔭 **在做的**：把学生工作里的重复劳动，一个个变成顺手的工具<br/>
🎛 **在实验的**：全模态生成（图 / 音 / 歌 / 视频）、Agent 工程、RAG 检索<br/>
💬 **可以聊**：AI 工具落地、学生工作提效、教育信息化、UI 设计规范 —— [提 Issue](https://github.com/xpsmsn/xpsmsn/issues) 找我

## 🤝 欢迎高校同仁加入

一个人盯不过来整个思政领域，一个人也写不全所有工具。**这些项目全部开源、MIT 协议，欢迎各校辅导员、思政课教师、教育技术同仁一起建设。**

| 你可以 | 怎么做 |
|---|---|
| 📡 推荐信源 | 思政智汇的 23 个信源之外，你关注的省市教育厅、兄弟高校官微，[提 Issue](https://github.com/xpsmsn/sizhengzhihui/issues) 推荐给我们 |
| 🗂 共建主题 | 四组十二个主题（辅导员 / 帮扶育人 / 安全稳定 / 党建……）按你学校的实际工作场景提调整建议 |
| 📝 反馈解读 | 政策解读的口径、视角、详略，一线辅导员最有发言权——[在线翻几篇](https://sizhenzhihui.cpolar.cn/)再告诉我们怎么改 |
| 🛠 贡献代码 | 全部仓库开放 PR；不会代码也没关系，描述清楚你想要的样子，剩下的交给 vibecoding |
| 🏫 自部署 | 一台 NAS + Docker Compose 就能跑起你学校的专属思政站，[部署指南](https://github.com/xpsmsn/sizhengzhihui#部署)写好了 |

> 也可以 fork 一份改成你学校的信源与分类——**这本来就是为复制而设计的**。
